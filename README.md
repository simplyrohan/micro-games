# micro-games
A game library for Arduino and ESP32 boards

# Purpose
With boards like the ESP32 and Arduinos, a big field is running games or emulators on it.
However, I wanted to make a simpler, and more lightweight game library. This library attempts to recreate the workflow that you would use when using the Python library `pygame-ce`. By keeping things similar, it will be fast and easy to port many existing games over to this library.
